# JSON Server Demo

This project demonstrates the use of JSON Server to create a mock REST API for development and testing purposes.

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the server with `npm start`.

## Features

- Mock REST API with customizable endpoints.
- Supports GET, POST, PUT, DELETE operations.
- Easy to integrate with frontend applications.
